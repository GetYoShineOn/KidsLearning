ALL-STAR MATH ARENA — deploy folder

This whole folder is the website. There is NO server or database.
Keep the structure exactly as-is (index.html at the top, icons in the icons/ folder).

QUICK DEPLOY (Netlify, free):
1. Go to https://app.netlify.com/drop
2. Drag THIS folder (math-arena-deploy) onto the page.
3. Wait ~10 seconds. You get a URL like https://random-name.netlify.app
4. (Optional) Site settings -> Change site name -> pick something memorable.

PUT ON THE iPad:
1. Open the Netlify URL in SAFARI on the iPad (must be Safari, not Chrome).
2. Tap the Share button (square with up-arrow).
3. Tap "Add to Home Screen" -> Add.
4. Launch from the new home-screen icon. It runs full-screen and works offline.

UPDATING LATER:
- Re-drag the updated folder to the same site (Deploys tab -> drag to deploy),
  then on the iPad open the app, pull down to refresh once while online.

NOTE: Progress is saved on each device only. No accounts, no data collected.
