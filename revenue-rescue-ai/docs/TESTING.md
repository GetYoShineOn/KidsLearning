# Testing
`npm test` (vitest, embedded Postgres). 36 tests: full journey (prospect -> audit -> outreach approval -> pilot -> missed call -> reply -> appointment -> job -> HIGH-confidence revenue -> metrics), quiet hours, STOP, no-auto-book, hostile inbound text, tenant isolation (metrics, cross-tenant writes/inbound), attribution rules, Stripe idempotency & simulated/real separation, auth/session tampering, webhook signatures (Stripe, Twilio), SSRF blocks, redirect-to-private, fetch failure, input validation, rate limits, estimate sanity.
Manual browser run (Playwright/Chromium, 390px viewport, production build): public audit -> pilot request -> admin login -> qualified prospect visible -> demo tenant -> tenant login -> dashboard with SIMULATED banner -> simulate missed call -> tenant blocked from /admin; no horizontal overflow.
NOT tested: real Twilio/Stripe, accessibility audit (axe), real-site audits (sandbox blocked external sites, so only the failure path ran against live network; HTML analysis is unit-tested via fixtures in the journey test), load, browsers other than Chromium.
