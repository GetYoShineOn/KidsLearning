# Financial model (scenarios, not forecasts)

Generated by `scripts/financial-model.mjs`. Every number is an **ASSUMPTION** until real customers replace it.
COGS = Twilio/SMS + A2P fees + number + LLM + payment fees + support time per customer per month. Fixed = hosting, DB, tools, domain per month, plus an assumed $4k/mo support hire per 40 customers beyond 25.
CAC = all sales cost per closed customer (founder time valued at 0 in early customers - **this flatters CAC**).
LTV = gross profit per month / monthly churn. Payback = CAC / gross profit per month.

## What would invalidate this
- Churn: home-service SMBs churn fast if they cannot see recovered jobs; the dashboard exists to fight this.
- COGS at scale depends on A2P 10DLC fees and carrier pass-through, verify with current Twilio pricing.
- CAC is guessed. The first 20 outreach conversations will replace it with a measured number.
